# 第2课完成：Modbus RTU 深度实践 — 多设备轮询

用户掌握了生产者-消费者模式在串口通信中的应用。核心知识点：
- 串口半双工特性决定了必须用队列调度
- `ConcurrentQueue<T>` + `AutoResetEvent` 实现线程安全的请求队列
- 消费者线程逐一出队、发送、等待响应的循环
- 设备状态管理（离线检测、连续失败计数、退避重试）
- 定时轮询器的设计（Timer + 配置表 + 跳过退避中的设备）

**已知现状**：用户的 TEST_101 项目当前是 "按钮→发送→事件回调" 模式，需要改造为 "队列→消费者→同步等待响应" 模式。
