C# Expert Agent agents/CSharpExpert.agent.md
★★★★★
项目关联度
95%

完整的 C#/.NET 专家 Agent，涵盖异步编程最佳实践（CancellationToken 全链路、ConfigureAwait(false) 规则）、 DI 设计、SOLID 原则、测试规范（xUnit/NUnit/MSTest 三框架写法）。强调：

  • 参数校验用 ArgumentNullException.ThrowIfNull
  • 最简暴露原则：private > internal > protected > public
  • 异步全链路传递 CancellationToken
  • 注释写 why 不写 what
  • 优先 modern C# 语法（file-scoped ns、raw string、switch expr）

🎯 建议采纳计划

分优先级，逐步整合到我们项目中

🟢 P0 — 立即采纳
  • 将 MVVM Toolkit Skill 的源生成器规则提取到 .claude/skills/mvvm-toolkit/
  • 使用 ArgumentNullException.ThrowIfNull 替代手写 null 检查
  • 确保所有 async 方法全链路传递 CancellationToken
  • 代码审查采用三级分类（CRITICAL / IMPORTANT / SUGGESTION）
🟡 P1 — 短期优化
  • 更新 CLAUDE.md 融入 C# Expert Agent 规范（异步、DI、测试）
  • 将 csharp.instructions.md 的关键规范写入项目 rules
  • PLC 新功能开发时用 Task Implementation 工作流追踪进度
  • 为 AlarmService / RecipeService 等关键服务编写单元测试（参考 Agent 测试规范）
🔵 P2 — 长期参考
  • 主构造函数语法在 .NET 10 项目中逐步采用
  • MCP Server 集成调研（未来 AI 功能扩展方向）
