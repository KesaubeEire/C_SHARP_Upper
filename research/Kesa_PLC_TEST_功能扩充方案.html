一、优先级与总体策略

级别说明目标
P0 核心基础设施 + 核心控件 + 核心功能立即可用，解决间距/规范问题
P1 重要重要功能扩充增强实用性
P2 增强增强功能 / 长期演进锦上添花
技术原则：
✅ 不引入新外部依赖（优先利用 SkiaSharp + Sharp7 + Wpf.Ui 现有体系）
✅ 新页面强制使用 MVVM 模式（[ObservableProperty] + [RelayCommand]）
✅ 所有控件遵循统一布局标准
✅ 颜色/画刷使用 DynamicResource 支持运行时主题切换

二、布局标准规范

基于 WPF UI Gallery 官方页面的观察，统一项目的间距规范：

页面外边距Margin="24" / "16"
卡片内边距Padding="16"
卡片圆角CornerRadius="8"
卡片之间间距Margin="0,0,0,12"
Section 之间Margin="0,32,0,0"
分组标题下间距Margin="0,0,0,8"
按钮间距Margin="4,0" / "8,0"
按钮高度28 ~ 32
输入框间距Margin="0,6"
列表项 paddingPadding="8,4"
标签列宽120 / 60 / Auto
字体: 标题/副标题/正文/次要20 / 16 / 14 / 12

🔧 需要修复的现有间距问题（P0 一并处理）

文件问题修复方案
IoMonitorPage.xamlAreaPanel 之间无间距AreaPanel 加 Margin="0,0,0,12"
ConnectionPage.xaml表单行间距 Margin="0,4" 过小→ Margin="0,6"
PollingPage.xaml按钮与状态栏之间无间距加 Margin="0,12,0,0"
BitBlock.xamlMargin="1" 过于紧凑→ Margin="2"
ByteRow.xaml各列间距无统一标准用 Margin 规范化
GaugeDashboardPage.xaml仪表之间 Margin="4" 过小→ Margin="8"
TrendChartPage.xaml工具栏间距不一致统一 Margin="0,0,0,8"

三、工具箱控件（Reusable Controls）

P0 核心工具箱控件

💡 LedIndicator

P0

多色 LED 指示灯 — 绿/红/黄/蓝/灰，支持闪烁动画

  • 依赖属性：Color, IsBlinking, Quality
  • 绑定 Quality 枚举自动切换颜色
  • Ellipse + Storyboard 动画
📄 Controls/Plc/LedIndicator.xaml + .cs

📟 ValueDisplayCard

P0

数值显示卡片 — 标题 + 数值 + 单位 + LED 质量戳

  • 标题 FontSize=12 次要色，数值 28 加粗，单位 14
  • Padding=16, CornerRadius=8
  • 支持 IsEditing 点击编辑模式
📄 Controls/Plc/ValueDisplayCard.xaml + .cs

📊 StatusStrip

P0

状态栏控件 — 连接状态 + 轮询间隔 + 错误计数 + 更新时间

  • 水平等间距分布
  • 放在页面底部 Margin="0,12,0,0"
📄 Controls/Plc/StatusStrip.xaml + .cs

🔄 BoolToQualityConverter

P0

质量戳转换器

  • true → #27AE60（绿/Good）
  • false → #E74C3C（红/Bad）
📄 Helpers/BoolToQualityConverter.cs

P1 增强工具箱控件

🔢 NumericInput

P1

工业数字输入 — 上下箭头递增/递减，长按连续变化

  • 可配置上下限、步长、小数位数
  • 回车/失焦触发确认事件
📄 Controls/Plc/NumericInput.xaml + .cs

🚨 AlarmBanner

P1

报警横幅 — 顶部滑入动画，级别变色

  • 红/橙/黄 三级
  • 显示时间 + 文本 + 确认按钮
  • 支持自动隐藏
📄 Controls/Plc/AlarmBanner.xaml + .cs

📈 ChannelLegend

P1

  • 点击切换可见性

📄 Controls/Plc/ChannelLegend.xaml + .cs
