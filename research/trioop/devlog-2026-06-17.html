✍️ 写入链路重构

旧链路：按钮 → writeVal(dbNumber, name, value) → POST imported-db-write → 后端查表 → 构造地址 → 写 PLC

新链路：按钮 → writePLC("DB1:转速", value) → 前端查 localStorage（映射+变量定义） → 构造地址 → POST write-raw → 后端透明透传 → 写 PLC
  • imported-db-write 废弃，改为极简 /api/plc/write-raw
  • 后端 0 逻辑：只调 plc.writeRaw() 或 plc.modifyBit()
  • 变量类型/偏移/位号全部由前端 localStorage 管理
  • Bool 走 RMW（modifyBit），数值走 writeRaw
  • 地址格式：Bool 用 B0.1（字节格式，非 X0.0），数值用 R2.1
  • 标签更新：改 DB 号时调用 updateTagAddressByDB → remove old tag → 改 s7addr → addItems
