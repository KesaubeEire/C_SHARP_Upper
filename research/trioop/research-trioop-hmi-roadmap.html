第二阶段：看得舒服 下一步

2.1 实时趋势曲线 📈

  • 选择变量 → 显示实时曲线（最近 N 秒滑动窗口）
  • 支持多变量叠加对比
  • 缩放、平移、暂停
  • 曲线颜色可配
  • 技术方案：前端用 Canvas + requestAnimationFrame 画，后端加一个环形缓冲区存历史快照

2.2 历史数据存储与查询 🗄️

  • 后端定时（如 1s/5s）将变量值写入 SQLite 或内存环形库
  • 前端选时间段 → 查询回放
  • 数据导出 CSV
  • 不引入 InfluxDB，保持零外部依赖，自实现时序存储

2.3 报警/事件列表 🔔

  • 条件配置：变量值 ≥ 阈值 / = 某个值 / 位上升沿/下降沿 触发报警
  • 报警产生 → 前端弹窗 / 声音提示 / 列表红闪
  • 报警确认（Ack）
  • 报警历史存储 + 查询
  • 例：状态_故障 == 1 → "设备故障" 报警

2.4 仪表盘 / 卡片布局 🎛️

  • 用户可自定义布局：拖拽组件到不同位置
  • 组件类型：数值卡片、仪表盘(Gauge)、指示灯、开关、进度条
  • 布局保存到 localStorage 或导出为 JSON
  • 类似 Grafana 的 Dashboard 概念

第三阶段：真刀真枪用 后续

3.1 用户登录与权限 🔐

  • 简单的登录页面（用户名 + 密码）
  • 角色：操作员（只读+写可写变量）、工程师（可改配置）、管理员（管理用户）
  • 操作审计日志：谁在什么时候改了哪个变量
  • 关键变量写入二次确认

3.2 配方管理 📋

  • 将一组变量值保存为"配方"（如 1号配方、2号配方）
  • 一键下发配方到 PLC
  • 从 PLC 读取当前值保存为配方
  • 配方导入/导出 JSON

3.3 系统诊断 🩺

  • 通信统计：轮询周期、响应时间、丢包率
  • 连接健康看板：重连次数、最后错误时间
  • 系统日志：操作记录、错误堆栈
  • 导出诊断报告

3.4 多屏/大屏适配 🖥️

  • 全屏模式（F11 一键全屏）
  • 大屏仪表板模式：深色主题、大字、自动轮播
  • 多标签页/页面路由
  • 键盘快捷键（如 F5 刷新、Ctrl+W 写入）

3.5 国际化 🌐

  • 中文 / English 切换
  • 变量名称可配别名（用于不同语言显示）

当前项目定位

这个项目本质上是一个 轻量级 Web HMI / 小型 SCADA，对标商业软件如：

  • 西门子 WinCC Web UX
  • 昆仑通态 MCGS 网络版
  • 叶帆 HMI
  • Node-RED Dashboard

优势：零依赖（不开 TIA Portal、不装 WinCC）、纯浏览器访问、代码可控。
