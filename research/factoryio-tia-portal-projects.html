🚀 快速开始：10 分钟跑通

推荐路径（方案 A）：Modbus TCP 直连，无博途依赖 
1. 打开 FactoryIO → 文件 → 打开场景 → Sorting by Height (Basic)
2. 按 F4 → 驱动列表 → 选择 "Modbus TCP/IP Server"
3. 配置 → 设置端口 502
4. 点击 CONNECT（绿色勾号）
5. 你的 WPF 上位机连接 127.0.0.1:502 即可
推荐路径（方案 B）：PLCSIM Advanced 
1. 下载官方模板: FactoryIO_Template_S7-1200_V15.zip
2. TIA Portal V21 打开 → 自动迁移
3. PLCSIM Advanced → 实例名设为 "factoryio" → Start
4. 博途 → 下载到设备 (PN/IE → PLCSIM)
5. CPU 切 RUN
6. FactoryIO → F4 → Siemens S7-PLCSIM → CONNECT
