项目问答预案

项目一：Web 端 SCADA 系统

架构：Node.js + Express · React + TypeScript · SQLite · S7 ISO-on-TCP / OPC UA 双协议

Q：S7 连接的稳定性怎么保证？

定时心跳（ReadArea 读状态字），发现断开自动重连，指数退避（1s → 2s → 4s → 上限 30s）。OPC UA 作为降级通道，S7 断开时自动切换。

Q：为什么做 S7 + OPC UA 双模式？

S7 轮询延迟低（最低 50ms），适合实时控制。OPC UA 订阅推送适合监控，跨品牌兼容性好（西门子/罗克韦尔/三菱）。

Q：拖拽仪表盘的数据更新怎么实现的？

WebSocket 长连接推送，按组件订阅数据点，死区过滤——变化超过阈值才推送，避免高频无效刷新。

项目二：WPF 桌面端 SCADA 系统

架构：C# .NET 10 · WPF MVVM · Sharp7 · SkiaSharp 渲染 · WPF-UI 控件库

Q：PollingScheduler 为什么分双通道？

I/Q/M 要求高刷新率（200ms），DB 块数据量大但不需要那么快。混在一起慢的 DB 操作会阻塞 I/Q/M。分通道用独立 S7 连接，互不干扰。

Q：S7Service 怎么保证线程安全？

SemaphoreSlim 加锁，请求串行化排队，所有读写走同一通道避免并发冲突。断开时自动丢弃队列中的待处理请求。

Q：BOOL 类型怎么解析？

PLC 中 BOOL 按 WORD 对齐打包（8 个 BOOL = 1 BYTE，起始地址必须是 BYTE 边界）。Sharp7 读回字节数组后按位掩码提取，不按字节读。

项目三：七轴分选/加工/组装/仓储监控系统

架构：C# .NET · 1511T + 1215C + 200 SMART · V90 伺服 x4 · G120 变频器 · 海康工业相机 · Profinet + Modbus TCP

Q：描述一下你的具体工作。

上位机全栈：S7 对接三台 PLC，V90 伺服实时曲线渲染，G120 变频器监控，海康相机 SDK 集成——视觉数据同步写入 PLC，报警系统。

Q：200 SMART 不支持 S7，你怎么接的？

Smart 仅支持 Modbus TCP/RTU，所以混用 Modbus TCP 接入。项目中同时掌握了 S7 + Modbus 两种协议。

Q：伺服实时曲线刷新周期多少？

≤200ms。定时轮询 V90 PZD 数据（转速/转矩/位置状态），SkiaSharp 硬件加速渲染趋势线。
