📦 1. 六大推荐项目（按学习优先级排序）

🥇

Industrial-WPF-HMI-Template

⭐ 上涨中（工业专用）
技术栈：WPF Prism CommunityToolkit.Mvvm SQLite
现代 WPF 工业上位机模板。模块化架构，包含实时监控、报警信号、PLC 集成、趋势曲线。支持 Native AOT。
✅ 最推荐 —— WPF + MVVM 是现代上位机标准写法，架构清晰，直接拿去改就能用
🥈

Simple-HMI-with-WPF

⭐ ~100
技术栈：WPF MVVM Light Siemens S7
简单的 WPF HMI 入门示例。Siemens S7 通信、实时趋势图表，代码量小、结构清晰，专为初学者设计。
✅ 入门首选 —— 一个下午能看完，快速理解 WPF HMI 基本骨架
🥉

SharpSCADA

⭐ ~200
技术栈：C# .NET Framework SQL Server Modbus OPC Profinet
轻量级工业网关 + 组态软件。插件架构，支持 Siemens Profinet、AB EtherNet/IP、Modbus、OPC 等多协议。
✅ 协议层学习最佳 —— 多协议集成的代码写法非常实战，做采集层必看
🏅

Rapid SCADA

⭐ 1,000+
技术栈：C# .NET Web + Desktop Modbus OPC PLC
功能最完整的开源 SCADA 平台。HMI 设计器 + 报警管理 + 趋势曲线 + 报表，无标签数量限制，持续维护中。
✅ 全貌学习 —— 看一个完整的大型 SCADA 系统是怎么设计的，适合有基础后啃
🔧

HslControlsDemo

⭐ 724
技术栈：C# WinForms WPF
工业 UI 控件宝库。仪表盘、开关、管道、阀门、传送带动画、实时趋势图等几十种控件，开箱即用。
✅ 控件即战力 —— 搭配 HslCommunication 库，快速搭出专业的上位机界面
🌐

FA Device Data Collector

⭐ 较新项目
技术栈：C# Vue Modbus OPC UA/DA S7 MQTT EtherNet/IP
制造业工业数据采集通用后台。支持 10 大工业协议，Web 可视化管理平台，Apache 许可。
✅ 前后端分离参考 —— C# 后端 + Vue 前端，适合想走 Web 化上位机方向

界面布局 + S7 通信 + 趋势图
→
第 2-3 天

学 MVVM + Prism +
模块化工业上位机架构
→
第 4-5 天
SharpSCADA
深挖协议集成层写法：
Modbus / OPC / Profinet
→
第 2 周
HslControlsDemo
把工业控件用起来：
仪表盘 / 管道 / 趋势图
自己拼一个上位机
→
第 3 周

HMI 设计器 + 报警 + 报表
💡 学习方式建议：不要只看代码。每个项目 clone 下来跑通 → 改一个功能 → 对比自己的项目想"我能怎么用"。 没有硬件也可以用 Modbus Slave 模拟器（免费）或 PLCSIM 来模拟 PLC。

💡 5. 学习建议

按你的简历技术栈选项目

你想加强什么优先看哪个
WPF 上位机架构（MVVM/Prism）Industrial-WPF-HMI-Template
Modbus / OPC 协议集成SharpSCADA、ModbusTCP源码C#
多 PLC 数据采集（Siemens S7）Simple-HMI-with-WPF、SharpSCADA
上位机 UI 控件/仪表盘HslControlsDemo
完整 SCADA 系统设计Rapid SCADA
前后端分离（C# 后端 + Web 前端）FA Device Data Collector、工业数据采集平台
没有硬件也能跑Simple-HMI-with-WPF + Modbus Slave 模拟器
🎯 面试加分策略：学完一个项目后，在简历上把它的思路融入你的项目描述。比如看了 SharpSCADA 的插件架构 → 面试时说"我的通信层参考了插件化设计，换协议只改配置不重编译"。这比泛泛说"我了解 Modbus"有说服力得多。
⚠️ 注意版本差异：SharpSCADA、FreeSCADA 等老项目基于 .NET Framework 4.x，和你的 .NET 10 项目有 API 差异。学设计思路和架构，代码写法用现代 .NET 语法（Span、Channel、record 等）。
