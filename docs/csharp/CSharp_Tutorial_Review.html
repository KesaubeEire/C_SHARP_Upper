18字符串处理方法 🔴 有错误

对应方法：Test30~Test35

✅ 教得正确的内容：

  • IndexOf 查找字符/字符串位置（找不到返回 -1）
  • Length 属性获取字符串长度
  • Substring 截取字符串（str.Substring(0, 7)）
  • ToLower / ToUpper 大小写转换
  • string.Format 数值格式化（{0:C} 货币格式）
  • string.Empty 和 "" 关系
  • null 与空串的区别（null 无法调用 .Length）
  • .Trim() 去两端空格
  • .LastIndexOf() 反向查找

🔴 错误：Test32 的注解

// 原文：==或Equals方法默认只能比较值类型或字符串类型。
//       对象类型（引用类型）是不能使用这种方式比较的。

错误原因：引用类型可以用 == 和 Equals，只是含义不同——== 默认比较引用地址，Equals 默认也比较引用，但可以被重写为值比较。

🟡 可改进：缺少 StringComparison

字符串比较应该使用 StringComparison.OrdinalIgnoreCase 而不是 .ToLower()（后者创建临时字符串且容易遇到土耳其语 i 问题）。

// ✅ 推荐：
bool eq = string.Equals(name3, name4, StringComparison.OrdinalIgnoreCase);

// ❌ 不建议：
bool eq = name3.ToLower() == name4.ToLower();

🔴 错误：越界代码直接执行

int[] netScore2 = new int[3] { 90, 56, 78 };
int myScore = netScore2[3];  // 这里会直接抛异常导致程序崩溃！

这段用于演示越界的代码没有被注释或 try-catch 包住，运行到此处会直接崩溃。建议：

try
{
    int myScore = netScore2[3];  // 故意越界
}
catch (IndexOutOfRangeException ex)
{
    Console.WriteLine($"越界了：{ex.Message}");
}
