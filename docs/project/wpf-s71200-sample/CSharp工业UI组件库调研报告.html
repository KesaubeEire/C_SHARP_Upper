🏭 HslControls 商业(试用8h)

工业物联网控件库 dathlin/HslControls
📦 GitHub 🌐 官网 📎 NuGet 🖼 Demo
专为工控上位机设计，C# 生态最全的工业图形控件库。 配合 HslCommunication 可以快速连接 Siemens/Modbus/Omron 等 PLC。
仪表盘 Gauge
实时曲线 Curve
管道 PipeLine
阀门 Valve
鼓风机 Blower
传送带 Conveyor
信号灯 SignalLamp
温度计 Thermometer
数码管 DigitalTube
液位瓶 Bottle
饼图/柱状图
电池/进度条
// NuGet
Install-Package HslControls

// XAML 使用仪表盘
<hsl:HslGauge Value="{Binding Pressure}"
   Min=0 Max=100 Unit="MPa" />

📈 LiveCharts2 MIT 免费

现代化图表库 LiveChartsCore.SkiaSharpView.Wpf
📦 GitHub 🌐 官网(示例) 📎 NuGet
开箱即用的现代化图表库，支持实时数据流刷新。 上位机趋势曲线的最佳选择，动画流畅、支持触摸交互。
实时折线图
面积图
柱状图
饼图/环形图
散点图
热力图
仪表盘 Gauge
地图 Map
// NuGet
Install-Package LiveChartsCore.SkiaSharpView.Wpf

// XAML
<lvc:CartesianChart
   Series="{Binding Series}"
   XAxes="{Binding XAxes}"
   YAxes="{Binding YAxes}" />

// 实时追加数据
series.Values.Add(new ObservablePoint(timestamp, value));

📉 ScottPlot.WPF MIT 免费

高性能科学绘图 ScottPlot.WPF
🌐 官网 📎 NuGet
纯 C# 编写、零依赖的高性能绘图库。 如果你只需要简单的实时曲线而不想引入大库，ScottPlot 是最轻量的选择。我们之前在 TEST_101 里已经用过 ScottPlot.WinForms。
折线/散点/柱状
信号图 SignalPlot
快速刷新 (10k+/s)
鼠标交互缩放
Install-Package ScottPlot.WPF

// XAML
<WpfPlot x:Name="plot" />

// 画实时曲线
plot.Plot.AddSignal(values, sampleRate: 100);
plot.Refresh();

🎯 ComponentOne C1.WPF.Gauge 商业

专业仪表控件 GrapeCity / MESCIUS
📎 NuGet 🌐 官网
如果需要精美表盘（指针、圆弧、色标段），这是 WPF 下最成熟的商业方案。 提供径向、线性、子弹图三种仪表类型，支持 MVVM 绑定。

线性仪表 LinearGauge
子弹图 BulletGraph
多指针/多量程

区间色标 Range

   Min=0 Max=100 />
