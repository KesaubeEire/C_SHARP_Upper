# 分类标签

Skill 使用五个标准分类角色。本文件将这些角色映射到本仓库问题追踪器中实际使用的标签字符串。

| Skill 中使用的角色 | 本仓库使用的标签 | 含义                           |
| ----------------- | ---------------- | ------------------------------ |
| `needs-triage`    | `needs-triage`   | 需要维护者评估该 Issue         |
| `needs-info`      | `needs-info`     | 等待提问者补充更多信息         |
| `ready-for-agent` | `ready-for-agent`| 已明确规格，AI 可直接接手处理  |
| `ready-for-human` | `ready-for-human`| 需要人工实现                   |
| `wontfix`         | `wontfix`        | 将不会被处理                   |

当 Skill 提到某个角色（如"应用 AFK-ready 分类标签"）时，使用上表中对应的标签字符串。

如有需要，编辑上表右侧列即可匹配你实际使用的标签词汇。
