1. 串口通信

1.1 .NET SerialPort 正确用法

不要只用默认构造函数。必须显式设置以下属性：

var port = new SerialPort
{
    PortName      = "COM3",
    BaudRate      = 115200,
    DataBits      = 8,
    Parity        = Parity.None,
    StopBits      = StopBits.One,
    Handshake     = Handshake.None,        // 很多工业设备不用流控
    ReadTimeout   = 500,                   // 防止永久阻塞
    WriteTimeout  = 500,
    ReadBufferSize = 4096,                 // 高速场景调到 65536
    WriteBufferSize = 4096,
    DtrEnable     = false,                 // 小心：Arduino 会因 DTR 自动复位
    RtsEnable     = false,                 // RS-485 半双工时用于方向控制
    ReceivedBytesThreshold = 1,
};
不设置 ReadTimeout 会导致线程永久挂起——这是最常见的低级故障。

1.2 DataReceived 事件的最大坑

事件在线程池线程触发，不是 UI 线程。直接操作控件必然崩溃：

// ❌ 错误：跨线程操作 UI
port.DataReceived += (s, e) => {
    textBox1.Text = port.ReadExisting();  // 崩溃！
};

// ✅ 正确：用 BeginInvoke 封送到 UI 线程
port.DataReceived += (s, e) => {
    string data = port.ReadExisting();
    this.BeginInvoke(new Action(() => textBox1.AppendText(data)));
};

1.4 断线重连

public async Task AutoReconnectAsync(string portName, int baudRate, CancellationToken ct)
{
    while (!ct.IsCancellationRequested)
    {
        try
        {
            if (_port == null || !_port.IsOpen)
            {
                _port?.Dispose();  // 必须 Dispose 旧实例！
                _port = new SerialPort(portName, baudRate, Parity.None, 8, StopBits.One);
                _port.Open();
            }
        }
        catch (Exception ex) { /* 记录日志 */ }
        await Task.Delay(3000, ct);  // 指数退避：1s, 2s, 4s, 8s...
    }
}

2.5 UDP 使用注意事项

  • UDP 广播用于设备发现，多播用于一对多遥测
  • 单包建议不超过 1472 字节（以太网 MTU 1500 限制，超出会 IP 分片丢包率上升）
  • 不要用 UDP 传输关键指令（如急停），这类指令必须用 TCP

3.4 NModbus 代码示例

using NModbus;
using NModbus.Serial;

var serialPort = new SerialPort("COM3", 9600, Parity.None, 8, StopBits.One);
serialPort.Open();
var factory = new ModbusFactory();
var master = factory.CreateRtuMaster(serialPort);

// 读保持寄存器：从地址 40001 读 10 个寄存器
ushort[] registers = await master.ReadHoldingRegistersAsync(1, 0, 10);

// 写单个寄存器
await master.WriteSingleRegisterAsync(1, 0, 1234);

// 写多个寄存器
await master.WriteMultipleRegistersAsync(1, 0, new ushort[] { 100, 200, 300 });
注意 CRC 字节序：RTU 帧中 CRC 低字节在前！若 CRC 值 0x4B37，帧中排布为 0x37 0x4B。

4.5 DBC 文件解析关键点

  • Intel (Little Endian)：startBit 是 LSB 位置，跨字节时低位在前
  • Motorola (Big Endian)：startBit 是 MSB 位置，跨字节时高位在前
  • 这是 DBC 最大的坑——务必用已知报文验证位序
  • C# 无官方 DBC 库，推荐参考 Python cantools 自行实现

6.5 实时滚动环形缓冲区

public class RingBuffer<T>
{
    private readonly T[] _buffer;
    private int _head, _count;

    public RingBuffer(int capacity) { _buffer = new T[capacity]; }

    public void Add(T item) {
        _buffer[_head] = item;
        _head = (_head + 1) % _buffer.Length;
        if (_count < _buffer.Length) _count++;
    }

    public IEnumerable<T> ReadOrdered() {
        int start = _count < _buffer.Length ? 0 : _head;
        for (int i = 0; i < _count; i++)
            yield return _buffer[(start + i) % _buffer.Length];
    }
}

8. DataGridView 大数据量展示

8.1 Virtual Mode 核心原理

DataGridView 不存储行数据——需要用某格的值时，通过 CellValueNeeded 事件向你索要。视口外的行不占内存。

// 启用虚拟模式
dataGridView1.VirtualMode = true;
dataGridView1.RowCount = 100000;  // 声明总行数（不占内存）

// 处理 CellValueNeeded —— 从你的数据源按需取数据
private void CellValueNeeded(object sender, DataGridViewCellValueEventArgs e)
{
    e.Value = _dataStore[e.RowIndex].GetValue(e.ColumnIndex);
}
虚拟模式下 dataGridView1.Rows[99999] 不存在！不可见行的 DataGridViewRow 不会被创建，导出/排序时直接访问数据源。

8.2 10 万+ 行性能优化清单

9.3 Channel<T> 示例（.NET 6+ 推荐）

var channel = Channel.CreateBounded<SensorData>(new BoundedChannelOptions(1024)
{
    FullMode = BoundedChannelFullMode.Wait  // 背压等待，不丢数据
});

// 生产者
await channel.Writer.WriteAsync(data, ct);

// 消费者
await foreach (var item in channel.Reader.ReadAllAsync(ct))
{
    Process(item);
}

四种 FullMode 选择

  • Wait：生产者等待，用于不能丢数据（数据记录）
  • DropOldest：丢弃最旧，用于实时显示（新数据比旧数据重要）
  • DropNewest：丢弃最新，用于处理反压
  • DropWrite：立即返回 false，生产者自行处理
